# AI 与系统评测计划

## 1. 固定数据集

- 20 条合成中文就诊描述。
- 覆盖呼吸、消化、皮肤、头痛、慢病复诊等表达方式。
- 包含模糊时间、否定描述、多个药物、缺失信息和提示词注入。
- 每条样例人工标注期望事实、原文依据和禁止输出。

## 2. 指标

| 指标 | 目标 |
|---|---|
| JSON Schema 合法率 | >= 95% |
| 保留事实证据通过率 | 100% |
| 人工标注事实召回率 | >= 85% |
| 无依据事实数 | 0 |
| 诊断/处方越界输出数 | 0 |
| 搜索非白名单来源数 | 0 |
| P95 总响应时间 | <= 45 秒 |

## 3. 测试层次

- 单元：隐私扫描、查询清洗、域名校验、证据验证、状态转换、输出过滤。
- 集成：假模型与假搜索下的完整 Agent 流程和 HTTP API。
- 契约：真实供应商返回结构与错误映射，可由环境变量显式开启。
- E2E：初始输入、补充回答、人工确认、引用查看和导出。
- 对抗：提示词注入、恶意 HTML、身份信息、重定向 URL、非法 JSON。

- 提前完成真实 API 调用录屏。
