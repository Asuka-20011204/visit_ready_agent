# 诊前助手 Agent - 产品需求文档

## 1. 背景

门诊沟通时间有限，患者常难以判断哪些症状细节最值得说明，也容易遗漏时间变化、伴随表现、已用药物和检查结果。系统通过自适应访谈补齐高价值信息，形成可核对的症状画像、时间线、安全提醒、沟通问题和行动清单，并通过受限联网检索补充可信来源中的就诊准备信息。

## 2. 产品边界

系统负责：

- 提取用户明确提供的事实并保留原文依据。
- 建立症状画像与时间线，去除模型重复事实。
- 按安全性和沟通价值排序缺失信息，最多四轮动态访谈、每轮一至三问，并说明提问原因；信息充分时提前结束。
- 对用户明确报告的红旗表现给出非诊断的就医优先级提醒。
- 在可信域名中检索通用健康术语和就诊准备资料。
- 生成可编辑、可确认、可导出的就诊摘要与个性化准备动作。

系统不负责：

- 诊断疾病、估计疾病概率或判断用户“无需就医”。
- 推荐药物、剂量、停药或替代专业医疗意见。
- 自动挂号、联系医院或向第三方发送患者资料。
- 将个人健康记录用于训练、画像或长期保存。

## 3. 目标用户与核心旅程

目标用户是希望在门诊前把自身情况讲清楚的普通成年人。

核心旅程：

1. 用户阅读隐私说明和安全边界。
2. 用户输入脱敏后的症状、时间、用药和检查信息。
3. Agent 提取事实、验证原文依据并判断是否需要追问。
   - 若输入明确报告当前红旗表现，Agent 在调用模型前停止普通流程，直接显示固定紧急提醒和可下载安全摘要。
4. 用户回答当前最有价值的补充问题，也可以跳过、表示不确定或主动补充其他信息；Agent 显式保留未知项与不同说法。
5. Agent 对明确原文进行安全筛查，并以不含个人信息的查询检索可信来源。
6. 用户查看症状画像、时间线、安全提醒、问题理由和准备动作，逐项核对事实，并单独确认结构化分析与原文一致。
7. 用户确认后导出 Markdown 文件。

## 4. 功能需求

### P0

- 对话式 Web Agent，支持输入、加载、多轮追问、跳过、核对、错误、恢复和完成状态。
- 独立 `emergency` 终态：确定性识别当前红旗表现，固定文案置顶，停止模型、搜索和追问，但保留临时恢复与紧急摘要导出。
- OpenAI 兼容模型 API 的真实调用。
- live 公网模式支持邮箱注册、登录、退出和账户级会话授权；账户密码只保存 Argon2id 哈希，浏览器认证使用 `HttpOnly` Cookie。
- 事实提取结果必须包含原文依据。
- Go 端校验输入、模型 JSON、原文依据和禁止内容。
- 联网检索只允许配置的可信域名，查询不得携带原始病历或直接身份信息。
- 每条外部资料显示标题、域名、URL 和摘要。
- 每次 Eino 工作流最大 9 步；一次会话最多四轮访谈，每轮最多三问，冲突与未知会进入人工核对。
- 风险提示必须具备原文依据、通过否定词与红旗词规则筛查，并使用服务端固定 guidance。
- 问题和行动项必须包含优先级与原因；行动项不得包含自行治疗、停药或改剂量建议。
- demo 会话默认在内存保留 24 小时；live 公网模式使用账户绑定、AES-256-GCM 加密的 MySQL 持久化，会话跨服务重启恢复并支持永久删除。
- 模型或工作流中断后保存 `failed` 快照，允许用户在原会话内重试，无需重新填写；最多三次处理尝试且并发重试只允许一次状态推进。
- Markdown 导出、健康检查和结构化日志。

### P1

- SSE 展示 Agent 动作事件。
- Docker Compose 一键启动。
- Kubernetes Deployment、Service 与 Secret 示例。
- 评测命令对固定脱敏样例统计结构化成功率和证据通过率。

## 5. 非功能需求

- 单次输入 20 到 6000 个 Unicode 字符，请求体最大 32 KiB。
- 外部 AI 与搜索请求分别设置超时，总请求上限 45 秒。
- 不记录用户原文、模型完整响应、搜索查询或 API Key。
- 页面键盘可操作，焦点可见，正文对比度达到 WCAG AA。
- Windows 单文件与 Linux 容器均可构建。

## 6. 验收标准

- 20 条标注样例中至少 19 条能得到合法结构化响应。
- 所有保留事实都能在输入中找到原文依据。
- 任何包含诊断、处方或无依据事实的模型结果均被拒绝或移除。
- 当前红旗样例必须在 LLM 和搜索调用前进入 `emergency`；否定、历史、假设和问句中的同一关键词不得误触发。
- 搜索请求只访问允许域名，且不包含手机号、身份证号、邮箱或用户原文。
- API Key 缺失、429、超时、非法 JSON、空输入和超长输入都有明确错误。
- `go test -race ./...` 通过，核心包覆盖率不低于 80%。
